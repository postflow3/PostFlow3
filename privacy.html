Política de Privacidade

Última atualização: 26 de outubro de 2026

Esta política explica como o PostFlow3 trata informações quando você cria uma conta, conecta plataformas sociais, prepara conteúdos ou agenda publicações. Use o serviço apenas com contas e conteúdos que você tem autorização para administrar.

1. Informações que podemos coletar

  • Cadastro e conta: informações que você fornece para criar e administrar sua conta, como endereço de e-mail e identificadores de usuário.
  • Contas conectadas: identificadores de perfil, informações básicas disponibilizadas pelas plataformas e dados necessários para manter a conexão autorizada.
  • Conteúdos e agendamentos: vídeos enviados por você, títulos, descrições, hashtags, destinos escolhidos, datas, horários e estados de publicação.
  • Dados técnicos e de operação: registros de erros, eventos de segurança e informações técnicas necessárias para operar, manter e proteger o serviço.
  • Dados recebidos por APIs do Google: quando você escolhe conectar uma conta Google/YouTube ou usar recursos relacionados ao Google Drive, o serviço pode receber os dados autorizados pelas permissões exibidas na tela de consentimento, incluindo identificadores da conta, informações necessárias para enviar vídeos e/ou localizar e gerenciar arquivos selecionados para os fluxos solicitados.

2. Como usamos os dados

Usamos as informações para criar e proteger contas, manter as conexões solicitadas, permitir que você selecione destinos, preparar e agendar publicações, transmitir conteúdos às plataformas escolhidas, mostrar estados e erros, oferecer suporte e cumprir obrigações legais. Só solicitamos acesso às informações necessárias para os recursos e permissões que você decide utilizar.

3. Uso de dados das APIs do Google

Quando você autoriza o PostFlow3 a acessar dados do Google, esses dados são utilizados para executar os recursos que você solicitou, como conectar sua conta YouTube, enviar vídeos ou interagir com arquivos do Google Drive quando essa função estiver habilitada. O PostFlow3 não vende dados do Google nem os utiliza para publicidade direcionada. Não utilizamos dados obtidos pelas APIs do Google para treinar modelos generalizados de inteligência artificial.

O acesso ocorre conforme as permissões exibidas na tela de consentimento. O PostFlow3 não deve acessar dados do Google para finalidades incompatíveis com a função autorizada. O uso e a transferência de informações recebidas pelas APIs do Google para outros aplicativos devem cumprir a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado quando aplicáveis.

4. Compartilhamento com plataformas e fornecedores

Para realizar uma ação solicitada por você, o serviço transmite os dados necessários à plataforma de destino escolhida, como YouTube ou Instagram. O Google, a Meta e outros provedores tratam os dados enviados a eles segundo suas próprias políticas. A infraestrutura de hospedagem e armazenamento utilizada pelo PostFlow3 também pode processar dados para disponibilizar o serviço. Não vendemos informações pessoais. Só divulgaremos dados em outras situações quando houver base legal ou necessidade legítima de proteger o serviço, seus usuários ou terceiros.

5. Armazenamento, segurança e retenção

O serviço utiliza infraestrutura técnica para armazenar e processar dados de conta, configurações e conteúdos necessários às funções utilizadas. Credenciais e tokens de acesso devem ser protegidos por controles de acesso e mecanismos de segurança apropriados. Nenhuma solução pode garantir segurança absoluta. Os dados são mantidos pelo período necessário para fornecer o serviço, cumprir as finalidades descritas e atender exigências legais. Arquivos de mídia podem ser removidos conforme os fluxos de publicação e as configurações disponíveis no serviço; não considere uma remoção concluída sem a confirmação apresentada pelo PostFlow3.

6. Permissões, revogação e exclusão

Você pode interromper o acesso de uma plataforma revogando a autorização nas configurações da própria plataforma. Para solicitar acesso, correção ou exclusão de dados pessoais tratados pelo PostFlow3, escreva para contasergio04@gmail.com, usando o endereço associado à sua conta quando possível e descrevendo sua solicitação. Podemos pedir informações razoáveis para confirmar a titularidade antes de atender ao pedido. Excluiremos ou anonimizaremos os dados quando apropriado, respeitando obrigações legais e registros que precisem ser mantidos por um período limitado.

7. Privacidade de menores

O PostFlow3 não se destina a pessoas que não tenham idade suficiente para usar legalmente o serviço ou as plataformas conectadas. Os usuários devem cumprir os requisitos de idade e os termos de cada plataforma.

8. Alterações nesta política

Podemos atualizar esta política quando os recursos, as práticas de tratamento ou as exigências legais mudarem. Publicaremos a versão vigente nesta página e atualizaremos a data indicada no início.

9. Contato e solicitações de privacidade

Para perguntas sobre esta política ou solicitações relacionadas aos seus dados, entre em contato com o responsável pelo PostFlow3 pelo e-mail contasergio04@gmail.com.
